## Problem Statement

Given 54 cartographic measurements collected across Roosevelt National Forest in Colorado,
predict which of 7 tree species (cover types) is dominant in a 30x30 metre forest patch.
This is a 7-class classification problem.

---

## Dataset

| Attribute | Detail |
|-----------|--------|
| Name | Forest CoverType Dataset |
| Source | UCI Machine Learning Repository |
| URL | https://archive.ics.uci.edu/dataset/31/covertype |
| Total Records | 581,012 |
| Used (sample) | 10,000 (stratified) |
| Features | 54 |
| Target | Cover_Type (classes 1-7) |
| Missing Values | None |

**Feature breakdown:**
- 10 quantitative: Elevation, Aspect, Slope, distances to water/roads/fire, hillshade readings
- 4 Wilderness Area binary indicators
- 40 Soil Type binary indicators

**Why this dataset?**
I chose CoverType because it has 54 features (well above the 12-feature requirement), 581k records,
and it is a genuinely challenging multi-class problem. Most classmates tend to pick Iris or Titanic,
so this stands out a bit more.

**Preprocessing:**
1. Stratified 10k sample to preserve class ratios
2. LabelEncoder: labels 1-7 mapped to 0-6
3. 80/20 stratified train/test split
4. StandardScaler fitted on training set only (to avoid data leakage)

## Observations

| Model | Observation |
|-------|-------------|
| Logistic Regression | Got 73.05% accuracy which was better than I expected for a linear model on this dataset. It seems the scaled elevation and distance features are fairly linearly separable for most classes. Struggled on minority classes like Cottonwood/Willow. |
| Decision Tree | Slightly lower than LR at 71.2%. I tried a few depth values (10, 12, 15, 20) and 15 worked best - deeper trees started memorising training patterns. The tree splits on Elevation at the root which makes geographic sense. |
| K-Nearest Neighbors | Best non-ensemble result at 74.1%. Scaling really mattered here - the 44 binary features would have dominated Euclidean distance without StandardScaler. k=7 came from plotting the elbow curve in the notebook. |
| Naive Bayes (Gaussian) | Only 10.45% accuracy which is the most interesting result to me. The Gaussian independence assumption completely breaks down here because 44 of 54 features are binary 0/1 values. After standardisation those are not Gaussian at all. The model just predicts one or two classes for almost everything. The AUC is still 0.67 which shows it has some ranking ability even if classification fails. |
| Random Forest | Best on every single metric - 77.95% accuracy, 0.9212 AUC, 0.6371 MCC. The ensemble averaging of 150 trees clearly helps compared to the single decision tree. OOB accuracy tracked closely with test accuracy so the model is not overfitting. |

**Winner: Random Forest** - it outperformed all others on all 6 metrics. The MCC of 0.637 is
particularly convincing since MCC accounts for class imbalance - class 2 (Lodgepole Pine) makes up
~49% of the data so a dumb classifier could fake ~49% accuracy. Random Forest's MCC confirms it
is genuinely learning to distinguish all 7 cover types.

---

## Evaluation Metrics Used

- **Accuracy** - overall correct / total
- **AUC (OvR weighted)** - ROC area for each class vs rest
- **Precision (weighted)** - true positives / (true + false positives)
- **Recall (weighted)** - true positives / (true + false negatives)
- **F1 (weighted)** - harmonic mean of precision and recall
- **MCC** - Matthews Correlation Coefficient, robust to class imbalance
